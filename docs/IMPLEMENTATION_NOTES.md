## P0 - Contract

- Six arrow templates generated by tools/gen_templates.py into
  assets/arrows/*.json (single source for TS + Python). Union semantics are
  represented as a primitive polygon SET rather than a boolean-merged
  outline: rendering draws all polygons as one instance (same instance_id,
  same depth), containment uses any-polygon. No polygon boolean ops needed;
  visual/mask/geometry semantics identical to a merged outline.
- Straight template uses the exact design-doc vertices. LEFT = rod + bend +
  head toward +b; RIGHT is the exact b-mirror of LEFT (asserted in
  tools/gen_templates.py). Combined arrows share the entry rod.
- All templates are bbox-centered (anchor = canonical bbox center = origin).
- Scene/labels JSON schemas in schemas/*.json (draft-07), shared by TS types
  (web/src/shared/types.ts mirrors field names) and validated in Python with
  jsonschema.
- Pixel convention: pixel centers at half-integers, principal point defaults
  to [W/2, H/2]. BEV: row 0 = x_max (far), col 0 = y_max (left); feature
  0.25 m/cell (64x32), GT mask 0.05 m/cell (320x160). Covered by
  tests/test_bev.py.
- JS/Python projection cross-check (tests/test_projection.py) runs a real
  three.js PerspectiveCamera (web/scripts/projection_check.ts via tsx):
  24 points x 3 camera variants (default, offset principal point 140/80,
  low pitch) max error <= 0.5 px (actual ~1e-12 for identical math, <=0.5
  allowed for engine differences). Also left/right + near/far image-order
  semantics, rigid-inverse round trips, and pinhole vs OpenGL-matrix path
  agreement.
- Default camera: f = H / (2 tan(fov_v/2)) = 166.277 px at 60 deg / 192 px.

## P1 - Minimal generation

- Shared scene construction (web/src/shared/scene_builder.ts) is the only
  implementation of ground/objects/lane lines/lanes/arrows; the render page,
  the batch worker and (later) the editor preview all consume it. Editor
  cannot diverge from offline rendering.
- render page (web/dist/render.html) exposes window.toyRenderer.renderSample
  with the documented passes. DEVIATION from the doc's sketch interface:
  passes return raw RGBA (base64) instead of base64 PNG; the Node worker
  encodes exact PNGs with pngjs. Reason: avoids canvas color management /
  premultiplied-alpha on the supervision path; bytes from
  readRenderTargetPixels go to PNG unchanged. Amodal masks are written as
  binary (0/255) PNGs.
- ID passes render into a WebGLRenderTarget with NEAREST filtering, no AA,
  MeshBasicMaterial, lights off, background forced to pure black (id 0);
  occluders get black MeshBasicMaterial with depth writes ON; lane markings
  hidden during ID passes (decorative geometry must not leak into
  supervision); ground writes depth in ID passes.
- Readback flips GL bottom-up rows to top-down exactly once; PNGs are saved
  top-down and never flipped again. decode_instance_ids (Python) = R +
  256*G + 65536*B.
- Known three.js pitfall fixed: OrthographicCamera with a mirrored frustum
  (left > right) flips triangle winding and backface-culls everything. The
  BEV top-down camera uses a NON-mirrored frustum with up=+x; the standard
  lookAt frame (x_cam=(0,-1,0), y_cam=(1,0,0)) already maps image-left to
  y_max and image-top to x_max. Regression-covered by
  tests/test_render_semantics.py.
- Occlusion labels: visible_px from the visible pass ID count, amodal_px
  from the per-arrow binary mask, occluded_px = amodal - visible;
  truncated/in_front from projecting template vertices (any vertex behind
  camera -> not in_front; any projected vertex outside the image ->
  truncated). Generation-time placement additionally requires >=64 px
  projected POLYGON area (shoelace) and >=4 px bbox short side; bbox-corner
  area was found to overestimate and was replaced (P1 finding).
- Occlusion tolerance: 0 px by default (renders are exact; boundary noise
  audit happens per-dataset in P3 with/without-object对照).
- P1 evidence: tests/test_render_semantics.py (BEV orientation/mirror/
  aspect, mask-RGB alignment, amodal==visible when unoccluded) +
  smoke script equivalent (clean scene all-valid; occluded scene: amodal
  unchanged, visible drops to 0, ignore_reason=occluded,
  allow_no_object=false).
